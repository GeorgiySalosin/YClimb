Курсовая работа. Приложение для автоматизации работы скалодрома на WPF. Использует локальную БД SQLite <br/><br/>

<h1> РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ </h1> <br/> 
После запуска программы пользователю откроется главное окно программы, представленное на рисунке 6. Если пользователь ранее не входил в систему, то откроется форма авторизации:
<img width="777" height="440" alt="image" src="https://github.com/user-attachments/assets/9cb1654e-febc-4699-9db5-cd4bc395df63" />

Рисунок 6 – Главный экран ПС, страница авторизации <br/><br/>

Можно войти в систему, зная ник либо электронную почту учетной записи и пароль к ней. Если учетной записи нет, можно ее создать, нажав “sign up” (рисунок 7). Длина пароля должна быть не менее 8 символов, а почта иметь формат “% @ % . %”
<img width="778" height="442" alt="image" src="https://github.com/user-attachments/assets/69add760-423f-45f9-b4fb-ec1eef2d6ac3" />

Рисунок 7 – Главный экран ПС, страница регистрации <br/><br/>

После регистрации и входа пользователь попадает на главную страницу приложения, откуда доступен весь тематический функционал приложения. По умолчанию открывается страница новостей, которая пополняется администрацией скалодрома (рис.8):
<img width="780" height="440" alt="image" src="https://github.com/user-attachments/assets/706ba9cc-30cf-43e8-a8ba-cc3be1e1c2fb" />

Рисунок 8 – Главный экран ПС, главная (лента новостей) <br/><br/>

При переходе во вкладку “routes” пользователь открывает ленту трасс, пополняемую людьми с любой ролью:
<img width="779" height="440" alt="image" src="https://github.com/user-attachments/assets/2ec7b8a1-f381-494e-9a61-b4bce9d92d41" />

Рисунок 9.1 – Главный экран ПС, главная (лента трасс) <br/><br/>

Здесь можно создать свою трассу, нажав кнопку “new route” (рис.9.2): при нажатии откроется контейнер для создания поста. Здесь можно ввести заголовок и добавить изображение трассы:
<img width="780" height="437" alt="image" src="https://github.com/user-attachments/assets/d5cc832a-eaef-4a7c-8798-c6ded5e3eff9" />

Рисунок 9.2 – Главный экран ПС, главная (лента трасс, создание трассы) <br/><br/>

При нажатии иконки “+” можно выбрать картинку, которая автоматически откроется в новом окне для разметки трассы (рис.10):
<img width="779" height="496" alt="image" src="https://github.com/user-attachments/assets/61f37ed4-2f1e-4a83-8604-d8e536c590ef" />

Рисунок 10 – Вспомогательный экран ПС, Окно редактирования изображения <br/><br/>

Здесь можно выбрать инструмент (круг - для выделения обычных зацепов / линия - для выделения угловатых форм, разметки старта, либо для подписей) и цвет (красный с белой обводкой - для стартовых и финишных зацепов / желтый с черной обводкой - для основной трассы). Чтобы отменить предыдущее действие, можно нажать иконку со стрелкой в нижней части.
